# How JUranometria works

This series explains the application through the boundaries that let it keep
growing. Each article follows one feature from source data to the reader and
shows which parts of the program are allowed to know about it.

These are explanatory documents. The binding architectural record remains
[Technical architecture](../architecture.md), together with the measured
decisions under [`docs/decisions/`](../decisions/).
