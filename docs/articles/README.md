# JUranometria articles

JUranometria is an atlas, but it is also an argument about how the sky should
be represented. These articles explain the astronomy and the architecture
behind that argument.

## Exploring the sky

- [From the celestial sphere to a page](from-celestial-sphere-to-page.md) —
  why detailed charts, wide overviews and celestial globes preserve different
  truths about the same sphere.

## How JUranometria works

- [Language without translating the sky](../how/language.md) — how canonical
  astronomical identity, chart names, interface prose, accessibility and
  export remain separate.
- [Projections: technical companion](../how/projections.md) — the source and
  decision trail behind the projection article.

The binding architectural record remains [Technical
architecture](../architecture.md) and the measured decisions under
[`docs/decisions/`](../decisions/). The articles explain those records; they do
not replace them.
