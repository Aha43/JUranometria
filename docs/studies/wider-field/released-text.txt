# Released page text, listed

What this file is: every piece of text the atlas draws on every released
page, with the box it occupies. The released-page digests say that a page
changed; this says what changed on it.

One line per label. A label that moves moves one line; a label the page
stops drawing takes its line with it; a label the page starts drawing adds
one. The `at` column is which of the label's stated candidate positions it
took - `0` is where the atlas has always drawn it - and `duress` marks a
label placed on the least bad of its candidates because none was free.

Boxes are measured text, so this file is a fact about the platform below as
well as about this repository, exactly as the pixel column of
`released-pages.txt` is.

Recorded on: `Mac OS X 26.5.2/aarch64/Homebrew 21.0.11`

Regenerate with `make released-text`.
