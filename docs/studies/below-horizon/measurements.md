# Subdue below horizon, on production pages

Sprint 55, issue #615. Generated by `juranometria.tool.BelowHorizonStudyMain` (`make below-horizon-study`) from compiled application classes: the pages are the production composition - `ChartComponent` with the meridian, ecliptic and Solar System modules attached - at the gallery instant, Oslo 59.913° N 10.752° E, 2026-03-20 21:33 UTC, the Sun -26.2° below the horizon. Beside each production page stands a mock-up at each candidate strength: every pixel whose sky position lies below the mathematical horizon is blended towards the ground, keeping the stated share of the ink's distance from it. The mock-up is a pixel operation, not the rule: it dims the horizon line and the furniture over the sky as well, and halves a word that straddles the horizon - what the rule must not do, shown so that the rulings on labels and on the line are made with the problem in view.

## The inks, by number
