# The #472 contract measurements, kept

Records the measurement that preceded the ruling, as `solar-system/moon-contract/` keeps the Moon's. None is regenerated by the evidence contract: each reads gitignored downloads (NAIF's `jup365.bsp`, 1.1 GB, pinned by `scripts/download-jovian-sources.sh`) or the 7-day Horizons matrices retained outside the repository, and each states the day it was measured.

- `authority-comparison.md` — Skyfield on JUP365 against every kept Horizons response (the committed subset and the retained 7-day matrices), by era: Jupiter, Io, Europa, Ganymede, Callisto; the X/Y basis; the visibility states against Horizons' codes; the named evening's transitions, equatorial-sphere definition. `scripts/jovian-authority-comparison.py`, run 2026-10-07.
- `december-2026-transitions-oblate.md` — the named evening with the oblate apparent figure and the PCK pole (`--december-only --oblate`).
- `deflection-jupiter-oslo.md`, `deflection-io-oslo.md` — the Oslo matrices with the Sun's gravitational deflection applied (`--deflect`), the experiment behind the apparent-place finding.
- `deflection-by-elongation-without.md`, `deflection-by-elongation-with-sun.md` — Jupiter's apparent-place differences banded by elongation from the Sun, both Jupiter matrices, without and with deflection.
- `pack-measurements.md` — the excerpt cut and proved with the released writer, the second half sized from the segment directories, the candidate intervals, the layouts (`make jovian-pack-study`).
